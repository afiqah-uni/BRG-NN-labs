# 1. Installing a Linux Environment on Your PC

## Introduction

This practical activity introduced me to setting up a Linux environment on my MacBook. The purpose was to install Ubuntu Linux using a virtual machine so that I could learn and practise Linux commands in a separate environment without replacing my existing operating system.

## Tools Used

- MacBook
- UTM (virtualisation software)
- Ubuntu Linux

## Practical Experience

I started by installing UTM on my MacBook and setting up a new virtual machine for Ubuntu. During my first attempt, I encountered an issue where the virtual machine would not run successfully. I was unsure what had caused the problem, so I decided to create another virtual machine and try the installation process again.

The second attempt was successful, and I was able to access the Ubuntu environment.

## Challenges and Troubleshooting

The main challenge I faced was getting my first virtual machine to run. Since I was still unfamiliar with virtualisation software and its settings, I could not immediately identify the cause of the problem.

Instead of continuing with the unsuccessful setup, I created a new virtual machine and repeated the process. This allowed me to get Ubuntu running successfully.

## Reflection and Learning Outcomes

Through this activity, I learned that virtualisation allows users to run another operating system within their existing computer. I also became more familiar with using UTM to create and manage a virtual machine.

This experience taught me that troubleshooting is an important part of system administration. When an issue occurs, it is useful to review the setup and try a different approach rather than assuming the entire installation process has failed.

I now have an Ubuntu environment that I can use for the subsequent practical activities.
